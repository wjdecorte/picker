# Weekly workspace
Mode: Operate.
Primary task: generate the weekly ATS card, review it, and save personal overrides inside the app.
Approved scope: This Week, History, Settings. Preserve the scouting ledger's navy/light palette and IBM Plex typography, while replacing the five overlapping navigation paths and repeated dashboards with one weekly list.
This Week: one Generate picks action; schedule/line refresh; current pick, model provenance, confidence, classification, result; inline overrides and evidence. A manual version never overwrites a model version. Games lock at kickoff.
History: weekly records, searchable prediction versions, independent snapshot grading, details/analytics behind disclosure.
Settings: OpenAI connection/model status and server environment guidance, data feed limits and backup export. Never render or accept a secret in client state.
Essential missing states: no server key, no week loaded, no odds, all games started, provider failure, generation in progress, invalid model response, save conflict, no historical results.
